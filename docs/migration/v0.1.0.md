# v0.1.0 전환 안내

`v0.1.0`은 첫 NATS JetStream 대상 버전입니다. 정식 태그 발행 전에는 `@preview`를 사용하세요. 기존 RabbitMQ와 Kafka 설정을 자동으로 변환하지 않습니다.

NATS 연결에는 Go 1.26.0 이상과 `spine.event-adapter/v1`을 제공하는 코어가 필요합니다. `spine.WithEventAdapter`에 `natsplatform.NewFactory`의 결과를 연결하고, stream과 보존 정책을 먼저 준비하세요. 설정과 전달 범위는 [README](../../README.md)를 따릅니다.

코어 의존성은 Preview `v0.7.0-preview.2`, RC `v0.7.0-rc.1`, 정식 `v0.7.0`으로 구분합니다. RC와 정식 코어 태그가 공개되기 전에는 해당 채널을 발행할 수 없습니다. [배포 절차](../releasing.md)에 따라 코어 고정 버전을 변경하고 검증한 후보를 한 단계씩 승격합니다.

Core NATS pub/sub, request/reply, wildcard, 자동 DLQ, DB/브로커 원자성과 exactly-once 업무 처리는 포함하지 않습니다. JetStream ACK 유실과 재전달에 대비해 소비자를 멱등하게 작성하세요.
