# v0.1.0-preview.1 출시 후보

Spine의 `spine.event-adapter/v1`을 구현하는 첫 NATS JetStream 후보입니다. Go 1.26.0 이상, Spine `v0.7.0-preview.2`와 `nats.go v1.55.0`을 사용합니다. 태그 발행 전에는 `@preview` 브랜치로 설치할 수 있습니다.

- `spine.WithEventAdapter`로 factory를 연결합니다. 발행은 stream 저장 확인을 기다리고 성공 처리는 서버가 확인한 ACK를 사용합니다.
- durable pull consumer와 기본 reject, 선택적 requeue 및 지연 재전달을 지원합니다. stream 생성과 보존 정책은 애플리케이션 운영자가 설정합니다.
- CLI 동적 조회용 `spine-platform.json`을 제공합니다. 이름별 환경 설정과 최소 Go 버전은 해당 메타데이터에 선언합니다.
- CI는 실제 NATS 송수신과 TLS/인증, 생성 앱 네 조합 및 미등록 이벤트와 validator 네 조합을 검사합니다. 공개 설치와 원격 CI의 실제 결과는 해당 실행 근거로 구분합니다.

Core NATS pub/sub와 request/reply, wildcard 소비, 자동 DLQ, DB/브로커 원자성과 exactly-once 업무 처리는 포함하지 않습니다. ACK 유실과 `AckWait` 초과에 따른 중복 처리를 고려해 소비자를 멱등하게 작성하세요.
